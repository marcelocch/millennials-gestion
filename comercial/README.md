# Página comercial (Millennials × Artisan)

Presentación interactiva que acompaña la demo: dolor por área, calculadora de cobranza,
recorrido de una venta, carrera del vendedor, preguntas de gerencia, inversión por hitos y guion de demo.

- `millennials-x-artisan.html`: la página lista para publicar (un solo archivo, logos incrustados).
- `plantilla.html` + `extra.css`: fuente. Usa el sistema visual de Artisan (azul de Prusia #023047,
  celestes para información, amarillo #FFB703 y naranja #FB8500 solo para dinero y acción;
  Montserrat para títulos, Bai Jamjuree para texto). Los estilos base vienen de la página de Royalty Barbershop.
- Los enlaces a la demo son la dirección de la demo más un `#escena` (ver `plugins/escenas.client.ts`).
  La dirección se puede cambiar desde la sección "Guion de la demo".
