# Millennials · Plataforma de gestión (demo)

Demo navegable con datos simulados de la plataforma de gestión propuesta a Millennials Investments.
Muestra el tablero de la gerencia y el día a día de cobranzas, demostraciones, reclutamiento,
inducción, telemarketing y la red de distribuidores.

```bash
npm install
npm run dev
```

Usa el selector "Ver la plataforma como" para recorrer la demo desde cada perfil.
El contexto del proyecto está en `CLAUDE.md` y en `docs/`.
